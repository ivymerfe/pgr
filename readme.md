# pgr

![logo](assets/logo.png)

Инструмент для захвата, воспроизведения и сравнения трафика PostgreSQL.

Читает трафик из `.pcap` или своего формата. Может проиграть его на другую базу и сравнить два захвата между собой. Перехватывает пакеты через eBPF.

## Установка

Бинарники: [GitHub Releases](https://github.com/ivymerfe/pgr/releases).

## Команды

### `capture` — записать трафик

```bash
pgr capture -o captures/session1 -i eth0 -a 10.0.0.5 -p 5432
```

| Флаг              | По умолчанию | Описание                                      |
| ----------------- | ------------ | --------------------------------------------- |
| `-o, --output`    | `zz_cap`     | Папка для записи захвата                      |
| `-i, --interface` | `lo`         | Сетевой интерфейс                             |
| `-a, --addr`      | `::1`        | Адрес сервера                                 |
| `-p, --port`      | `5432`       | Порт сервера                                  |
| `-c, --chunk`     | `0`          | Номер чанка, с которого начать (для дозаписи) |
| `-m, --max-chunk` | `1GiB`       | Максимальный размер чанка                     |
| `-l, --level`     | `3`          | Уровень сжатия zstd                           |
| `--zw`            | `4`          | Число потоков сжатия                          |

Захват разбивается на чанки: при превышении `--max-chunk` начинается новый файл.

### Формат аргумента capture

`replay`, `dump` и `compare` принимают захват строкой: `path[:port]@[offset][+duration]`

- `port` — порт трафика в захвате (.pcap), по умолчанию `5432`
- `offset` — с какого момента читать (`2m`, `1h30m`...), по умолчанию с начала
- `duration` — сколько читать, по умолчанию до конца

`captures/session1`, `captures/session1@2m+5m`, `capture.pcap:5432+10m`

### `replay` — воспроизвести захват

```bash
pgr replay captures/session1@2m+5m -h 127.0.0.1 -p 5433 -d mydb -u postgres
```

| Аргумент         | По умолчанию | Описание                                        |
| ---------------- | ------------ | ----------------------------------------------- |
| `input`          | —            | Захват (см. формат выше)                        |
| `-a, --addr-map` | `replay.csv` | Файл соответствия адресов (нужен для `compare`) |
| `-h, --host`     | `127.0.0.1`  | Хост целевого сервера                           |
| `-p, --port`     | `5432`       | Порт целевого сервера                           |
| `-d, --dbname`   | `postgres`   | Имя базы данных                                 |
| `-u, --user`     | `$USER`      | Пользователь БД                                 |
| `-P, --pass`     | —            | Пароль                                          |

### `dump` — выгрузить в CSV

```bash
pgr dump captures/session1:5432 -o capture.csv
```

| Аргумент       | По умолчанию  | Описание                 |
| -------------- | ------------- | ------------------------ |
| `input`        | —             | Захват (см. формат выше) |
| `-o, --output` | `capture.csv` | Путь выходного CSV       |

### `compare` — сравнить два захвата

```bash
pgr compare -s captures/session1 -r captures/session2 --addr-map replay.csv --delta diff.csv
```

| Флаг             | По умолчанию | Описание                                               |
| ---------------- | ------------ | ------------------------------------------------------ |
| `-s, --src`      | —            | Исходный захват (см. формат выше)                      |
| `-r, --replay`   | —            | Захват результата `replay` (см. формат выше)           |
| `-a, --addr-map` | `replay.csv` | Файл соответствия адресов, полученный на шаге `replay` |
| `--delta`        | —            | Файл для сохранения различий                           |

## Сборка

Нужен [Rust/Cargo](https://www.rust-lang.org/tools/install), nightly toolchain и [bpf-linker](https://github.com/aya-rs/bpf-linker):

```bash
rustup toolchain install nightly
cargo install bpf-linker
```

```bash
cargo build --release
```
